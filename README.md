# The poem about permission

This make.fun bounty entry is a small program that writes a short poem about agency to `/output/entry.txt`. Run it with `python3 main.py`; it creates the output directory when needed, falls back to `entry.txt` in the current directory if `/output` is not writable, and checks the written poem.

> I knocked for sugar,
> borrowed one cup.
> She gave me two—
> and the courage to ask again.
